## 利用枠と費用の解釈

利用枠はアカウント共通です。別のチャットによる消費もあり得るため、作業前と各段階の境界で現在値を確認します。確認不能・古い情報を正常と扱いません。短期・週次など当該実行に適用される枠を評価し、いずれかの残量が5%以下なら作業を続けません。確認間隔の間や1つの実行中の減少を完全にリアルタイム検出できるとは保証しません。小さな単位、時間上限、頻繁なチェックポイントで停止遅延を抑えます。

ユーザーが使用を許容しているのは、手動で使用する期限の近い無料回復枠だけです。この準備で確認された失効時刻は **2026-10-04 14:08:26 JST** です。これは回復を自動実行する許可ではありません。表示が変わった、期限を過ぎた、対象を特定できない、無料か確認できない場合は使用しません。他の回復枠・有料クレジット・自動購入を代替手段にしません。

回復後はユーザーからの再開指示を受け、新しい利用枠情報を確認して保存済みの地点から続けます。費用禁止は利用枠回復後も継続します。

## 実装上の初期選択

- まず追加の依存関係を抑えた静的Webアプリと、Node.js標準機能で動くローカル処理を検討します。
- 文章データは差分を確認できる構造化ファイルを優先します。特定のDB製品は必須条件ではありません。
- 論文解析のAI APIキーは要求しません。自動取得・解析が既存枠や許可された取得方法で実現できない部分は明示して止めます。
- GitHub Actionsや外部ホスティングの実行を、無料だろうという推測で自動追加しません。
- 実装担当が変更できるのは `app/`、`tests/app/`、`scripts/app/`、`docs/app/`。ハーネスと評価基準は対象外です。
- エージェントに渡す操作は `project_list`、`project_read`、`project_write`、`project_checks`、`project_view_evidence` 相当の限定ツールとします。レビュー担当には書き込みを渡しません。
- app-serverはリポジトリを作業ルートとする読み取り専用の標準環境を使います。シェル・統合実行・アプリ・プラグイン・hooks・ブラウザ・標準画像表示・Web検索・各MCPを明示的に無効化します。計画用などの副作用のない標準ツールは残る場合があります。
- 実機で確認できた読み取り専用の標準環境を採用し、`environments: []` は使用しません。限定ツールの実行に必要な `code_mode_host` は有効のままにします。
- 信頼された検査はネットワーク禁止・check-workだけ書き込み可能と確認したCodex OSサンドボックス内で実行します。候補Nodeテストには追加の権限制限を設け、アプリ・テスト・アプリスクリプト・package.json・test-tempのみ読み取り、test-tempのみ書き込み可能にし、子プロセスとネイティブアドオンを禁止します。信頼されたワーカーがテストを直接読み込み、レポート・画像は候補から保護します。
- 画面検査には既存のChrome / Edgeを使い、ダウンロードしません。QAは `file:` URLで通常のscriptとローカルfixtureを使って動かし、`--allow-file-access-from-files` と `--disable-web-security` は使用しません。
- Windowsでの二重サンドボックスが動作しないため、Chrome / Edgeの `--no-sandbox` は境界確認済みのCodex OSサンドボックス内だけで使用します。ホストで直接使わず、ネットワーク・書き込みのOS制限と通常のブラウザCORSを維持します。
- 公開用データの整合は `app/manifest.json` で検査し、QA専用の架空データを完成データとして数えません。
- 初期エンジンは機能QAが通った後も全体を `needs_data` とし、形式上の件数・収録状態 だけで完成にはしません。実論文の出典と文章のレビューを後続工程として行います。

## 今後の作業で確定する事項

1. 実収集時点の各会議の正式最新年、対象トラック、公式一覧、本文の利用可能性。
2. 公式一覧・本文の取得方法と利用条件。全件を無料かつ適切に読めるか。
3. 少数の実論文による説明の深さ・文字量・カテゴリ粒度の検証。
4. 実測した配信容量、一時領域の上限、閲覧の応答性。
5. 公開するかどうか。GitHub Pagesの公開は「URLを知る本人だけ」に限定できない。
6. 端末間の個人データ自動同期が必要か。現時点では実装しない。

未決定事項があっても、表示・保存・データ検査など依存しない作業は進められます。未確定の科学的説明・収録件数・取得許可・公開許可を推測で確定しません。
